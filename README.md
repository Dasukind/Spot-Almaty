# SpotAlmaty

A map of photo and video shoot spots in Almaty.

## Problem
Photographers waste time searching for good locations.

## Features
- Map of spots
- Photo examples for each spot
- Best time of day by light
- Permit information

## Target users
Photographers in Almaty.

## Status
Course project (SOE 102). Prototype in Figma.
